Assistente Contábil com IA

Sistema web desenvolvido por **João Filipe** para praticar e aprimorar habilidades em desenvolvimento web full stack, utilizando Inteligência Artificial aplicada à contabilidade.

> ⚠️ Projeto com fins educacionais — criado para aprendizado de Node.js, Express, consumo de APIs de IA e integração frontend/backend.

## 🎯 Objetivo do Projeto

Este projeto faz parte do meu portfólio pessoal de desenvolvimento web. O foco principal é:
- Praticar Node.js com Express no backend
- Manipular APIs REST de Inteligência Artificial
- Construir interfaces com HTML5, CSS3 e JavaScript puro
- Entender o fluxo completo de uma aplicação web full stack

## ✨ Funcionalidades

- 🤖 Classificação automática** de transações contábeis via IA
- 📊 Identificação da natureza** da conta (débito/crédito)
- 📝 Geração de histórico padronizado** para lançamentos
- 💰 Extração de valores** mencionados na descrição
- 📋 Cópia rápida** para área de transferência
- 🎨 Interface responsiva** com exemplos prontos

## 🚀 Tecnologias Estudadas

| Tecnologia | Uso no Projeto |
|------------|----------------|
| **Node.js** | Servidor backend |
| **Express** | Rotas e API REST |
| **API NVIDIA** | Inteligência Artificial (Mixtral 8x7B) |
| **HTML5** | Estrutura da página |
| **CSS3** | Estilização e responsividade |
| **JavaScript** | Lógica do frontend |

## 📋 Pré-requisitos

- Node.js (versão 18 ou superior)
- NPM (gerenciador de pacotes do Node)
- Chave de API da NVIDIA (gratuita para testes)
